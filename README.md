A text analysis tool that when given a text file, outputs each word in the text in alphabetical order, along with the frequency of the word and lines that it appears on. 
It can also search for a given word to output the lines that it appears on and the frequency. 

The example text being analysed is "sherlock.txt". To change this, go to \TextAnalysisTool\bin\Debug and replace sherlock.txt with another text file. 
Make sure the Program.cs file (line 9) reflects this change before attempting to run.
